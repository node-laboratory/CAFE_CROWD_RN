# Figma → 코드 변환 가이드

Figma 디자인을 React Native(Granite) 코드로 변환할 때, 아래처럼 정리해 두면 변환이 수월합니다.

---

## 1. 변환 시 필요한 것 (Figma MCP/도구가 쓸 수 있는 조건)

- **선택된 노드**: 변환할 **화면 하나**를 하나의 Frame으로 두고, 그 Frame의 **node-id**를 알려주세요.
  - 예: `node-id=54-501` → 해당 프레임만 변환 대상이 됩니다.
- **텍스트**: 레이어 이름이나 텍스트 내용이 최종 문구와 같으면 그대로 코드에 반영됩니다.
- **색상**: Fill이 단색이면 HEX 등으로 추출 가능합니다. 변수(Variables)로 쓰면 더 좋습니다.
- **이미지/아이콘**: Export 가능한 형태(벡터 또는 PNG 등)로 두면 에셋으로 받을 수 있습니다.

---

## 2. 권한 동의 화면(54-501)을 코드로 옮기기 쉽게 하려면

### 권장 Figma 구조

1. **루트 Frame 1개**
   - 이름: 예) `LocationConsent` 또는 `위치 권한 동의`
   - 크기: 375 x 812 (모바일 기준) 권장
   - 이 Frame 하나에 `node-id=54-501`처럼 ID가 붙어 있어야 합니다.

2. **텍스트 레이어**
   - 제목, 설명, 버튼 문구를 **각각 Text 레이어**로 두세요.
   - 레이어 이름을 `title`, `description`, `button`처럼 구분해 두면 매핑하기 쉽습니다.

3. **버튼**
   - 버튼 영역은 **한 개의 Frame 또는 Rectangle**으로 묶고, 배경색을 지정해 두세요.
   - 텍스트는 그 안에 별도 Text로 두거나, Frame 이름에 `버튼` 등 역할을 적어 두세요.

4. **아이콘/이미지**
   - 위치 아이콘 등이 있으면:
     - **Vector** 또는 **Component**로 두고 Export 설정을 해 두거나
     - SVG/PNG로 내보낼 수 있게 해 두세요.
   - 레이어 이름에 `icon-location`처럼 용도를 적어 두면 좋습니다.

5. **색상**
   - 브랜드 색(`#EDB07F` 등)은 Figma **Variables**로 정의해 두면, “Primary” 등 이름으로 코드에 매핑하기 쉽습니다.
   - 단색 Fill이면 변환 시 HEX로 추출 가능합니다.

---

## 3. 이렇게 하면 변환이 어려운 경우

- **이미지로만 있는 텍스트**: 스크린샷/이미지 안의 글자는 추출이 어렵습니다. 반드시 **Text 레이어**로 두세요.
- **너무 깊은 중첩**: Frame이 10단계 이상 깊으면 구조 파악이 어렵습니다. “화면 = 1개 Frame + 그 안에 제목/설명/버튼 그룹” 정도로 단순화하세요.
- **복잡한 효과**: 블러, 여러 겹의 그라데이션 등은 RN에서 비슷하게만 구현 가능할 수 있습니다. 단색·단순 그라데이션 위주로 두면 재현도가 높습니다.

---

## 4. 54-501 노드로 다시 변환 요청할 때

- Figma MCP 한도가 풀리면, **“node-id=54-501인 화면 그대로 코드로 만들어줘”**라고 요청하시면 됩니다.
- 또는 **54-501 화면의 스크린샷**을 보내주시면, 레이아웃·문구·색을 참고해 `index.tsx`(위치 권한 동의 화면)를 맞춰 드릴 수 있습니다.
